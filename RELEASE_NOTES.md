# Lumio Stream 0.7.0

macOS 14+ / Apple silicon · unsigned, non-notarized preview

- Per-library **Preserve existing folder structure**, real folder browsing with indexed metadata, explicit title-view switch, independent TV series/season classification and targeted rescans. Parent folders no longer borrow child-series artwork.
- Metadata Studio source inspection: exact admin-only paths, real child folders/files, original-file audio/video preview, manual provider matching and existing metadata/episode corrections. Traversal and symlink escapes are rejected.
- **Manage existing Cloudflare Tunnel** in read-only monitoring mode: Account ID/Tunnel ID/API credential, Test connection, verified identity/capabilities and revalidated Save. The persistent server monitors without replacing external connectors or changing DNS/configuration.
- Overview separates local bind, local Media Center endpoint, configured HTTPS endpoint and actual tunnel-monitor/connector status. A configured URL is explicitly unverified.
- Aligned backup/restore actions through a shared responsive layout.
- Expanded audio integrates browser Back/collapse with the exact prior browsing context. The refined grooved record uses a clean center label, crisp artwork and reduced-motion-aware playback animation.
- Fix library-review conflicts caused by transient scan fields and noncanonical object ordering.

Earlier server/Admin independence, mobile navigation, PWA behavior and playback features are retained. Focused checks and limitations are in VERIFICATION_REPORT.md. No real Cloudflare API credential/control-plane management, public hostname, external metadata-provider lookup, physical display-off/lock, Windows or clean-machine Gatekeeper qualification is claimed. Existing external services and user media/data are preserved.
