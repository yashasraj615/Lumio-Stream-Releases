# Source availability

The application source repository remains private. Version-specific GPL source snapshots are attached to each release as Lumio-Stream-vX.Y.Z-source.tar.gz; SOURCE_INDEX.json records exact source commits and SHA-256 hashes. No repository history, local profiles or credentials are included.

The shared runtime source archive on v0.8.1 contains the exact bundled Jellyfin server/web sources and Jellyfin FFmpeg v7.1.4-3 source, patches and pinned dependency build recipes. Original third-party licenses/notices remain bundled in each DMG. External static dependency source archiving and redistribution review remain incomplete; no claim of complete corresponding-source compliance or production readiness is made. All installers remain unsigned, non-notarized development previews.
